Semáforo da Comunicação Web

Guia de boas e más práticas de comunicação em interfaces web.

🟢 Boas práticas 🟡 Cuidado 🔴 Evitar

🟢 VERDE: Boas práticas

🟢

Linguagem Clara

Use frases curtas, diretas e vocabulário simples para que todos compreendam a mensagem rapidamente.

🟢

Feedback Visual

Sempre avise o usuário sobre o resultado de uma ação (ex: "Formulário enviado com sucesso").

🟢

Hierarquia de Informação

Utilize tamanhos diferentes de texto (h1, h2, h3) para guiar a leitura de forma intuitiva.

🟢

Textos Alternativos

Sempre descreva o conteúdo de imagens usando o atributo alt para leitores de tela.

🟢

Contraste Adequado

Garanta que o texto tenha alto contraste com o fundo para usuários com baixa visão.

🟡 AMARELO: Cuidado

🟡

Uso de Jargões

Evite termos técnicos ou jargões da área, a menos que tenha certeza de que o público os entende.

🟡

Ícones sem Rótulos

Símbolos podem ser ambíguos. Sempre que possível, acompanhe ícones com rótulos de texto.

🟡

Animações em Excesso

Podem distrair ou até causar tontura em pessoas com sensibilidade visual. Use com moderação.

🟡

Formulários Longos

Podem cansar o usuário. Se houver muitos campos, divida em passos menores e claros.

🟡

Notificações/Pop-ups

Podem frustrar o usuário se interromperem uma tarefa. Ofereça um botão claro para fechar (X).

🔴 VERMELHO: Evitar

🔴

Depender Só da Cor

Nunca use apenas a cor (ex: texto vermelho) para indicar erros. Use também texto ou símbolos.

🔴

Textos Minúsculos

Fontes muito pequenas dificultam a leitura no celular. O tamanho mínimo recomendado é 16px.

🔴

Links Genéricos

Evite usar "clique aqui". Pessoas que usam leitores de tela precisam saber para onde o link vai (ex: "leia o relatório").

🔴

Áudio Automático

Vídeos ou sons tocando sozinhos assustam o usuário e prejudicam quem usa leitores de tela.

🔴

Bloqueio de Teclado

Nunca crie elementos que não possam ser acessados ou fechados usando a tecla "Tab" e "Esc".
